# 📊 Superstore Sales Analysis

## Overview

This project presents an **Exploratory Data Analysis (EDA)** of the Superstore Sales dataset using Python. The analysis focuses on cleaning the dataset, exploring sales patterns, visualizing business performance, and generating meaningful insights that can support business decision-making.

---

## Objectives

- Perform data cleaning and preprocessing
- Explore sales and profit trends
- Analyze category and sub-category performance
- Study regional sales distribution
- Identify top-performing products and customers
- Visualize key business metrics
- Generate actionable business insights

---

## Dataset

- **Dataset:** Superstore Sales Dataset
- **Records:** 10,194
- **Features:** 21 Columns

The dataset contains information about orders, customers, products, sales, profit, discounts, regions, and shipping details.

---

## Key Business Insights

- Total Sales generated: **$2,326,534.35**
- Total Profit earned: **$292,296.81**
- Technology category generated the highest profit.
- The West region achieved the highest overall sales.
- Consumer customers contributed the largest share of sales.
- Sales peaked during November and December.
- Several products generated exceptionally high sales, indicating valuable high-performing items.

## How to Run

1. Clone this repository

```bash
git clone https://github.com/Sarthak-Paturkar/Superstore_Sales_Analysis.git
```

2. Move into the project directory

```bash
cd Superstore_Sales_Analysis
```

3. Install the required libraries

```bash
pip install -r requirements.txt
```

4. Open the notebook

```
notebook/Superstore_EDA.ipynb
```
